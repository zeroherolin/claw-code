 Look at the split-index files (sharedindex.*) first (ls -l; a link shows an arrow, ->). If one is a link, git did not make it so, and git reads the index through it: do not run git in this folder, and use a fresh clone from the remote (with no remote: a new folder and git init), copy your files over by hand, but not the .git folder, then retry there. Keep this folder: commits that you have not pushed, other branches and stashes exist only here. If none is a link, do not delete any of these files by hand: the index may need one of them, and which one can change whenever git writes the index. Use a fresh clone in this case too, by the same steps.
