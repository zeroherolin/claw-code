Two things still work: a server started in the sandbox is reachable from outside it (the user's browser), and a client that honours the proxy environment variables (inside the sandbox they are spelled in lower case, `http_proxy` and `https_proxy`), such as curl, reaches a local port once its host and port are allowed, spelled as in the URL (`"127.0.0.1:3000"` in `sandbox.network.allowedDomains`). Wherever a local address is allowed, keep the port: a bare host opens every local port. Sandboxed commands can be let connect to local ports with `sandbox.network.allowLocalBinding: true` in ${…} (a project's settings do not count on Windows), after which  and Claude Code has to be restarted; that is their decision, not yours.
